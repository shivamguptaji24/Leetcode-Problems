# 🚀 LeetCode Problem of the Day — Solutions & Visualizations
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

Welcome to the **LeetCode POTD Hub**!  
This repository contains daily problems from [LeetCode's Problem of the Day](https://leetcode.com/problemset/all/) 🌟 along with:

- ✅ Clean & optimized **Java solutions**
- 🧠 Detailed **explanations**
- 📝 In-code **visualizations** (as comments after each solution)
- 🗓️ Updated regularly to stay consistent and sharp

---

## 📌 What's Inside?

🔹 **Language Used:** Java  
🔹 **Topics Covered:** Arrays, Strings, Trees, Graphs, DP, Binary Search, and more  
🔹 **Extra Edge:** Every `.java` file ends with a well-written **commented visualization** to make the logic crystal clear!

---

## 💻 How to Use

1. **Clone the Repository**
   ```bash
   git clone https://github.com/shivamguptaji24/Leetcode-Problems.git
   cd Leetcode-Problems
   ```

2. **Explore the files**  
   Open any `.java` file to see the code, followed by an in-code textual explanation or visualization written as comments.
